# Lộ trình (dự thảo)

1. Bootstrap workspace, hợp đồng, giao diện, SQLite, CI và kiểm chứng loopback.
2. PROJECT-08 cung cấp Design System và application shell. PROJECT-08.1 bổ sung kiểm thử BF-06 cho focus khi đổi breakpoint, vòng Tab với nội dung động, Escape của tooltip và scroll lock ở viewport thấp. Xem [Design System](DESIGN-SYSTEM.md).
3. PROJECT-09 cung cấp Dashboard với catalog, health thực tế và lộ trình học. PROJECT-09.1 bổ sung gộp probe đồng thời, kiểm tra slug duy nhất và hướng dẫn build theo API_PORT. Xem [Dashboard Design](DASHBOARD-DESIGN.md).
4. PROJECT-10 xây dựng nội dung kiến thức.
5. PROJECT-11 Security Isolation xử lý BF-02. Đây là cổng bắt buộc trước chức năng cố ý dễ tổn thương. Kiểm chứng cô lập tiến trình, hệ thống tệp, trình duyệt và mạng bằng fixture vô hại.
6. Hoàn thiện phòng thực hành, phân tích mã, nhật ký và báo cáo theo các mốc tiếp theo.
